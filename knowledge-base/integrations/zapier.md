# Zapier integration

Available on the **Growth plan and above**. Connect Ledgerly to 6,000+ apps through Zapier.

## Triggers

- Invoice sent
- Invoice paid
- Invoice overdue
- New client created
- Payment failed

## Actions

- Create client
- Create draft invoice
- Send invoice

## Example zaps

- Post a Slack message when an invoice is paid.
- Create a Ledgerly client when a deal is won in your CRM.
- Add a row to Google Sheets for every payment.

## Set up

Search for "Ledgerly" in Zapier and sign in with your Ledgerly account. Zapier uses an API key from **Settings →
API**; each zap counts toward your [API rate limits](https://docs.ledgerly.example/api/rate-limits).
